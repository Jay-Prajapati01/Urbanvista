Graphify integration notes

- Location: graphify/ (repo cloned here)
- Virtual environment: graphify/graphify-venv
- Quick run (PowerShell):

  Set-Location graphify
  .\graphify-venv\Scripts\python.exe -m graphify --help

- Helper wrapper: graphify/tools/run_graphify.ps1 (activates venv and runs graphify)

- To let agents run Graphify, use the wrapper or call the venv python with `-m graphify`.
